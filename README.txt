«Сибирь Проект» — многостраничный сайт
======================================

Что внутри
----------
  index.html                  — главная: H1, инфографика, услуги,
                                калькулятор стоимости, FAQ, чек-лист, контакты
  about.html                  — о компании и слово руководителя
  uslugi/                     — каталог услуг и 6 отдельных страниц:
      index.html                все услуги и цены
      bankovskie-garantii.html  независимые (банковские) гарантии
      tendernoe-soprovozhdenie.html  тендерное сопровождение
      kik.html                  кредитование исполнения контракта
      faktoring.html            факторинг под госконтракты
      ecp.html                  электронная подпись
      zashchita-fas.html        защита интересов в ФАС
  news/                       — новости (раздел + 6 материалов)
  articles/                   — полезные статьи (раздел + 4 материала)
  checklist.html              — экранная версия чек-листа (noindex)
  assets/files/               — PDF-чек-лист «Проверь себя перед тендером»
  assets/img/                 — логотипы, иконки, фотографии
  css/style.css               — все стили
  js/main.js                  — меню, анимации, калькулятор, FAQ, отзывы
  robots.txt                  — правила для поисковых роботов
  sitemap.xml                 — карта сайта
  llms.txt                    — описание сайта для ИИ-поиска (GEO)
  .htaccess                   — настройки Apache: кодировка, сжатие, кэш

Как опубликовать
----------------
1. Распакуйте архив.
2. Загрузите содержимое папки в корень сайта на хостинге
   (обычно public_html, www или htdocs) по FTP/SFTP
   или через файловый менеджер хостинга.
   Важно: файл index.html должен оказаться в корне, а не во вложенной папке.
3. Проверьте сайт в браузере — он сразу готов к работе.

Сайт работает без сборки и базы данных. Внешние ресурсы — Google Fonts и Google Analytics 4.
Анонимный чат работает на собственном сервере через /api/chat.php (PHP + GigaChat);
сторонние виджеты и Jivo не используются. Калькулятор считает в браузере
и не собирает персональные данные.

Совместимость
-------------
  Подходит для любого хостинга: Apache, Nginx, IIS,
  а также Netlify, Vercel, GitHub Pages, Cloudflare Pages.
  PHP и MySQL не требуются.
  Шрифты загружаются с Google Fonts — при желании их можно
  подключить локально.
