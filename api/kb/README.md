# База знаний ИИ-консультанта (RAG)

Папка используется и PHP-чатом сайта (`api/chat.php`), и запасным Python-бэкендом (`chatbot/backend/main.py`).

## Что уже загружено

- `documents/01-checklist-12-tochk.txt` — текст PDF-чек-листа «12 критических точек проверки заявки до подачи (44-ФЗ и 223-ФЗ)»;
- `documents/02-article-*.txt` — тексты всех статей раздела «Полезные статьи» (`sibirproekt72.ru/articles/`).

Источники извлечены скриптом `tools/extract_sources.py` (нужен `pypdf`: `pip install pypdf`). При обновлении PDF или статей запустите:

```bash
python sitenew/api/kb/tools/extract_sources.py
```

## Как работает поиск

`api/kb/search.php` (PHP) и `chatbot/backend/main.py` (Python) читают все `*.txt` из `documents/`, режут их на фрагменты ~900 символов с перекрытием, ищут по токенам запроса и подмешивают до 4 релевантных фрагментов в системное сообщение GigaChat. Отдельного индекса и пересборки нет: новый файл сразу участвует в поиске.

Формат каждого файла:

```
# SOURCE: исходное-имя.pdf
# TITLE: Заголовок документа
# URL: https://sibirproekt72.ru/...

текст документа
```

## Раздел загрузки файлов

Админка: `https://sibirproekt72.ru/kb-admin.html`.

1. В `api/config.php` задайте `kb_admin_token` (длинная случайная строка). Без токена загрузка отключена. Пример есть в `api/config.example.php`.
2. Откройте `/kb-admin.html`, введите токен.
3. Загрузите `.txt`, `.md`, `.html` или `.pdf`.
   - PDF: если на хостинге доступна утилита `pdftotext`, текст извлечётся автоматически. Иначе приложите текстовый файл в поле «Текст PDF» либо сразу загрузите `.txt`.
4. Документ сразу попадает в поиск — пересборка индекса не требуется.

Кнопка «Удалить» в списке документов удаляет соответствующий `.txt`.

## Важно

- База знаний дополняет системный промпт, но не отменяет его ограничений: не придумывать услуги, акции и цены.
- Пользовательские сообщения и история чата по-прежнему не сохраняются на сервере.
- Не публикуйте `api/config.php` и токен администратора в открытом доступе.
